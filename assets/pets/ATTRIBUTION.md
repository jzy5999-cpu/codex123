# codex123 Curated Pets Attribution

The initial curated pet set is generated from Google Noto Emoji image resources.

- Upstream project: https://github.com/googlefonts/noto-emoji
- Upstream README states that tools and most image resources are under the Apache License, Version 2.0; emoji fonts are under SIL Open Font License 1.1.
- codex123 uses PNG image resources as the visual basis and converts them into Codex-compatible `spritesheet.webp` files.
- Each pet directory includes a README with the source image URL.

Curated pets included in this release: Noto Cat, Noto Dog, Noto Fox, Noto Panda, Noto Rabbit, Noto Penguin, Noto Owl, Noto Hamster, Noto Unicorn, and Noto Dragon.
